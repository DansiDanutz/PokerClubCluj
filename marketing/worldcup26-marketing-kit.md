## 2. The 7-Day Organic Launch Playbook

Growth order that actually works for a referral product: **warm network → their networks → niche communities → broad social.** Don't start broad.

### Day 1 — Foundation
- Set up/clean profiles: **Instagram + TikTok + X** (same handle, bio link = your referral link).
- Pin one post explaining the game in 3 lines + 18+.
- **Personally** message your 20–30 closest contacts (NOT a broadcast list — 1:1 converts 5–10×). Use the WhatsApp "with hook" copy.

### Day 2 — Warm groups
- Post in **group chats you're genuinely part of** (football buddies, office, uni). Use the group-friendly copy so it reads as an invite, not an ad.
- Ask 3–5 friends who joined to each invite 3 of theirs — this is the compounding loop.

### Day 3 — Short video #1 (the clip you sent)
- Post the vertical video to **TikTok + Instagram Reels + YouTube Shorts** with the caption above.
- Hook in first 2 seconds: text on screen — "World Cup pick'em — pick 3, win the pool."
- CTA end card: "Code 26BC4B90CB · link in bio · 18+."

### Day 4 — Communities (highest-intent strangers)
- Football **subreddits, Discord servers, Telegram channels, Facebook groups**.
- **Read each group's rules first** — many ban referral links. Where links aren't allowed, post value (your bracket/picks) and let people ask. Self-promo bans are the #1 reason links die.

### Day 5 — Creator seeding
- DM 5–10 **micro-influencers** (5k–50k followers) in football/fantasy. Offer them an agent code (the site's "1 free code per 10 sold" reseller deal) instead of cash. Micro > mega for conversion.

### Day 6 — Short video #2 + proof
- Post a second angle: "How scoring works" or "My 3 picks and why."
- Screenshot the **leaderboard / your entry** as social proof (real proof > hype).

### Day 7 — Push + measure
- Re-share to stories, run a "last call before kickoff" message to warm contacts.
- **Measure:** signups per channel (use the ref link everywhere so attribution is clean). Double down on whatever channel actually converted; drop the rest.

### Repeat-engine after Day 7
Every member becomes a node: make it stupidly easy for each new joiner to grab their **own** referral code and re-run Day 1's 1:1 invites. That's the only thing that reaches large numbers — not you posting more.

## 3. Reality Check on "thousands of members ASAP"
- **Referral math beats blasting.** If each member brings ~2 others and a third of them activate, you compound. 1 → 30 personal invites → their invites → … That's how you reach 1,000s. Spammed links get blocked and convert ~0%.
- **Warm + communities convert; cold broadcast doesn't.** Expect WhatsApp/Telegram warm network and football communities to deliver the first few hundred. Broad TikTok/Reels can spike if a video hits, but it's variance — post consistently (1–2 short videos/day) and let one break out.
- **Fix the funnel or growth leaks:** the signup page should make the 18+ gate, the rules, and "what do I win" obvious in 5 seconds. (See the audit — add 18+ gate, responsible-gaming link, operator identity; these also reduce account bans and chargebacks.)
