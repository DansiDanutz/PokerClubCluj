Finding details

PC-001 · Framework advisories

Evidence: package.json pinned Next.js 14.2.35, and npm audit --omit=dev reported high-severity advisories affecting that release.

Resolution: Fixed Next.js and its matching ESLint configuration were upgraded to 15.5.22 in f9538a6.

PC-002 · Vulnerable transitive processors

Evidence: the original lockfile resolved PostCSS 8.4.31 under Next.js; audit also identified vulnerable Sharp/libvips releases.

Resolution: Fixed the dependency graph now resolves PostCSS 8.5.23 and Sharp 0.35.3. Node 20.9 or newer is required by the patched image processor.

PC-003 · Unbounded petition request bodies

Evidence: all eight petition POST routes called req.json() directly, without checking content type, decoded shape, declared size, or streamed size.

Resolution: Fixed a shared reader now accepts JSON objects up to 16 KiB and returns controlled 400, 413, or 415 errors before route logic and Supabase calls. The regression suite covers all eight routes.
